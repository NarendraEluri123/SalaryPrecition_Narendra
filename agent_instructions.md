# Agent Instructions

## Project Overview
This is a binary classification ML web application that predicts adult income (<=50K vs >50K) using the UCI Adult Census Income dataset.

## Key Files
- `train_model.py` — Must be run before the app. Trains and saves models.
- `app.py` — Streamlit app. Loads saved model and serves predictions.
- `data/adult.csv` — Raw dataset (do not modify).
- `models/model.pkl` — Trained sklearn Pipeline (generated by train_model.py).
- `models/feature_info.pkl` — Feature metadata dict used by app.py.

## Rules
- Never hard-code prediction logic in app.py. All predictions go through `model.predict()`.
- All file paths must be relative (use `os.path.dirname(os.path.abspath(__file__))`).
- Do not use absolute paths or system-specific paths.
- If the dataset changes (e.g., new columns), re-run `train_model.py` to regenerate the pipeline.
- No API keys are required for this project. If integrating an LLM later, use environment variables from `.env`.

## Adding a New Model
1. Import the estimator in `train_model.py`.
2. Add it to the `candidates` dict.
3. Re-run `python train_model.py`.

## Deployment Checklist
- [ ] `models/model.pkl` committed (or `train_model.py` runs on startup)
- [ ] `models/feature_info.pkl` committed
- [ ] `requirements.txt` up to date
- [ ] No absolute paths in any file
- [ ] No secrets or API keys in code
